# Changelog

All notable changes to the "antigravity-chat-organizer" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [0.2.8] - 2026-09-13

### Added
- **Dual Title Search**: Quick Search (`Ctrl+Alt+S`) now searches across both custom renamed titles and original Antigravity titles simultaneously.
- **Tree View Inline Search**: Renamed conversations now include `[Orig: <original title>]` in their tree description and tooltip, enabling instant direct matching via VS Code's inline tree filter (`Ctrl+F`).
- **Global Keybinding**: Added `Ctrl+Alt+S` (and `Cmd+Alt+S` on macOS) to instantly summon the Quick Search dialog from anywhere in the IDE.
- **Enhanced Search QuickPick**: Detailed secondary preview line displaying original title, session ID, user notes, and first prompt snippet.

---

## [0.2.7] - 2026-09-13

### Added
- **Smart Resume (Continue with Agent)**: Launch a fresh Cascade agent session pre-loaded with previous session context, linked implementation plans, walkthrough reports, user notes, and core objectives.
- **Antigravity State Sync**: Direct SQLite synchronization from `state.vscdb` to extract official conversation titles generated by Antigravity IDE.
- **Copy Conversation Title**: 1-Click action to copy the exact Antigravity title to clipboard for native `🕒 Past Conversations` search.

---

## [0.2.6] - 2026-09-13

### Added
- **Workspace Folder Launcher**: 1-Click action to switch to the workspace directory associated with any historical chat session.
- **Full Scratch Convo Ingestion**: Guaranteed inclusion of scratch and ad-hoc chat files from `.gemini/antigravity-ide/conversations`.

---

## [0.2.0] - 2026-09-12

### Added
- **Project Plans & Artifacts View**: Dedicated sidebar view to explore all historical `implementation_plan.md` and `walkthrough.md` files across all sessions.
- **Deep Full-Text Search**: Search inside raw `transcript.jsonl` files for code snippets, error logs, and commands with contextual preview snippets.
- **Native Drag & Drop**: Drag conversations directly into custom folders in the tree view.
- **Workspace Scope Filter**: Toggle between current workspace conversations and global history.

---

## [0.1.0] - 2026-09-11

### Added
- Initial release.
- Sidebar conversation tree view with auto-scan of Antigravity brain sessions.
- Custom folders, emoji badges, pins, and custom renaming.
- Export conversations to clean Markdown files.
